# Lab Manuals On QR Code

We have made this web application using SpringBoot framework and MySQL database.

#description of our system 💻

This system is divided into four panels: admin, coordinator, faculty, and student. Each panel has its own specific roles and responsibilities.

The admin panel is typically accessible only to authorized personnel who have been given the responsibility of managing the system. This panel is used to manage faculty members and assign responsibilities to coordinators and faculty members. The admin panel is also responsible for ensuring the smooth functioning of the system and addressing any technical issues that may arise.

The coordinator panel is responsible for mapping the lab manuals to the respective faculty members. They have the authority to control all the subjects and changes whenever required. The coordinators also work closely with the admin panel to ensure that the system is running smoothly.

The faculty panel is accessible only to faculty members and is used to update the lab manuals and make any necessary changes to the content. They are responsible for ensuring that the lab manuals are up to date and that the students have access to the latest information.

The student panel, on the other hand, is accessible to all students. They are allowed to view the contents of the lab manuals and download PDFs. The student panel is designed to provide students with easy access to information about their labs and experiments, helping them to better prepare for their classes.

Overall, this system is designed to make the management of lab manuals and experiments more efficient and effective. By dividing the responsibilities among different panels, it ensures that the system runs smoothly and that all stakeholders have access to the information they need.

#steps to start application 🪜
 
1)download and extract zip file.🗃️

2)open this project in ide like intellij,spring tool suite🌱 etc.

3)to start application : run spring boot application run (class having @SpringBootApplication annotation) file.💁🏻‍♀️ 

4) if application is successfully started then view output at : localhost:9090(you can change port number in application.properties file)/main <- front page of our application will be displayed locally here. 😊

[ Note :- you need to create database in your system and then configure database details in application.properties file like database url,username, password ]
